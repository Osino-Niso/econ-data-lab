# 石油ショックの歴史データ：探索的照合（2026-10-26）

**目的は観察事実を再計算すること。供給・需要・予備的需要ショックの「識別」や、ULC→CPIの因果効果の推定ではない。** 値はオンライン公開表から手入力転記した固定スナップショットであり、取得時点でデータをAPI経由で自動更新する仕組みではない。

## ソースと変数定義

| CSV列 | 観測対象／単位 | 出典・抽出方法 |
| --- | --- | --- |
| `japan_cpi_index_2015_100` | 日本、年平均の全国CPI（総合）、2015年=100の指数 | OECD Data Explorer, `JPN.A.N.CPI.IX._T.N.` (COICOP 2018価格指数、1960年代までの歴史系列も掲載)。https://data-explorer.oecd.org/vis?df%5Bag%5D=OECD.SDD.TPS&df%5Bid%5D=DSD_PRICES_COICOP2018%40DF_PRICES_C2018_ALL&dq=JPN.A.N.CPI.IX._T.N.&pd=1955%2C2024&vw=tb 。1972–1981年の掲載値を手転記。 |

欠測は空セルのまま（0％と解釈しない）。1974年ULC+30％、1979年ULC−3％は1981年時点の製造業の歴史統計であり、2026年の日銀BOX2の**経済全体**の国民経済計算ULC（名目雇用者報酬÷実質GDP）と計算概念・基準時点が異なる。2026年の資料と一致しているように見えても、**独立の同一系列による完全な再現とは書けない**。1974年の全国CPI前年比23.10％は、同BOX2の「約25％」と対象統計・集計方法・時点が異なる。

## 計算結果とその読み方

- 日本全国総合CPIの年平均指数前年比：1974年+23.10%、1979年+3.75%、1980年+7.80%。これは**日銀講演の「食料・エネルギー除くCPI」の前年比**とは異なる系列。
- 日本の製造業ULC前年比：1974年+30%、1979年−3%。同じ年の製造業産出価格：1974年+28%、1979年+6%。**1979年にULCが減っても製造業産出価格が上昇した**（労働費用以外の投入費用・マージン・需要なども動く）。同じ年に相関しただけで方向を特定することはできない。
- 世界の石油供給量：1973年59,300千bpd→1974年59,391千bpd（+0.15%）、1978年64,225千bpd→1979年66,973千bpd（+4.28%）。**年平均供給増は、その年に供給ショックが起きなかった証拠ではない**。予想された産油量、世界需要、在庫調整、油質、四半期・月次内の時点の違いが残る。
- 米国のOPEC産原油陸揚げ費用（月次の単純年平均）：1978年14.334ドル/bbl→1979年21.340ドル/bbl（+48.88%）。1978→79年に**世界供給量増と原油輸入費用高騰が同居した**という観察だけでは、供給・世界総需要・予備的需要の成分を識別できない。

## 識別に必要なもの

Kilian (2010), *Oil Price Volatility: Origins and Effects* （WTO公開）https://www-server1.wto.org/spanish/res_s/publications_s/wtr10_forum_s/wtr10_kilian_s.htm は、原油価格変動を**供給ショック・世界の実体経済活動に伴う需要ショック・将来の供給不安を反映する石油市場固有の需要ショック**に分けて考えることの重要性を指摘。石油生産量、世界実体活動、実質原油価格に関する時系列モデル等を用いても、ラグ、同時点制約、在庫、期待の扱いなど**追加の識別仮定**が要る。本データセットは油価・供給の記述統計なので、SVAR等の因果識別を実施していない。

関連する異なる実証設計として、日本銀行（2026年4月）『展望レポート』BOX2図表B2-8 https://www.boj.or.jp/mopo/outlook/gor2604b.pdf は、**同サイズの輸入物価上昇を設定したモデルシミュレーション**で、原油価格上昇ショックと円安ショックのGDPデフレーターの反応が逆向きになることを示す。ただしこれは実測値そのものではなく、モデルの仮定に依存する。

どちらも新しい外部ライブラリ／ネットワーク接続は不要。2つのCSVをローカルで読み込み、前年比と年平均を計算し、主要値が期待と一致することをassert/stopifnotで確認する。**固定値との照合は計算間違いを検出するだけであり、出典の正しさや転記・統計系列の完全互換性を証明するものではない。**
