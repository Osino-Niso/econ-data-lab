## OECD製造業ULCのより長い系列と資料年代の頑健性

追加した `oecd-manufacturing-ulc-1971-1981.csv` は[FRED系列JPNULCMANAPNMEI（OECD Main Economic Indicators、Benchmarked Unit Labor Costs - Manufacturing, Japan）](https://fred.stlouisfed.org/data/JPNULCMANAPNMEI)から1971～81年の**年次前年比・％**を転記したもの。2014年10月3日最終更新、現在はDISCONTINUED扱い。日本製造業ULCの1974年は**+27.2526％**、1979年は**−1.3770％**、1980年は**+4.7171％**。1981年英国議会の掲載値はそれぞれ1974年+30％・1979年−3％で**全く同じ数値ではない**が方向は一致する。

**1990年英国議会資料についての未確認事項：** 過去の調査メモには、[1990年11月19日の英国議会掲載資料](https://hansard.parliament.uk/Commons/1990-11-19/debates/5d87c114-21a5-4dbc-b2f2-7e4bddbea523/WrittenAnswers)に日本の製造業ULC指数（1985年＝100）が1978年105.0、1979年105.2、1980年104.7と記載された、との転記がある。この**原表を今回直接確認できず**、原典の表題・対象列・数値の帰属を独立検証できていない。転記値を前提とすれば前年比は1979年約+0.19%、1980年約−0.48%となるが、**未検証の値として記事本文から除外**した。将来、直接原資料を確認した場合にのみ分析へ再採用する。本文に掲げる差異は、原典を照合できた1981年議会資料（1974年+30%、1979年−3%）とFREDの2014年保存系列（1974年+27.25%、1979年−1.38%）に限る。

欠測は空セルのまま（0％と解釈しない）。1981年時点の資料で1974年ULC+30％、1979年ULC−3％は製造業の歴史統計であり、2026年の日銀BOX2の**経済全体**の国民経済計算ULC（名目雇用者報酬÷実質GDP）と計算概念・基準時点が異なる。2026年の資料と一致しているように見えても、**独立の同一系列による完全な再現とは書けない**。1974年の全国CPI前年比23.10％は、同BOX2の「約25％」と対象統計・集計方法・時点が異なる。

## 計算結果とその読み方

- 日本全国総合CPIの年平均指数前年比：1974年+23.10%、1979年+3.75%、1980年+7.80%。これは**日銀講演の「食料・エネルギー除くCPI」の前年比**とは異なる系列。
- 日本製造業ULC前年比（**2014年収録OECD系列**）：1974年+27.25%、1979年−1.38%、1980年+4.72%。1981年議会資料のOECD引用値は1974年+30%、1979年−3%で、FREDとは数字が異なるものの傾向は共通。同じ年の製造業産出価格：1974年+28%、1979年+6%。**1979年にULCがほぼ横ばい近傍でも製造業産出価格が上昇した**（労働費用以外の投入費用・マージン・需要なども動く）。系列の時点による差を隠さず、因果関係を特定しない。
- 世界の石油供給量：1973年59,300千bpd→1974年59,391千bpd（+0.15%）、1978年64,225千bpd→1979年66,973千bpd（+4.28%）。**年平均供給増は、その年に供給ショックが起きなかった証拠ではない**。予想された産油量、世界需要、在庫調整、油質、四半期・月次内の時点の違いが残る。
- 米国のOPEC産原油陸揚げ費用（月次の単純年平均）：1978年14.334ドル/bbl→1979年21.340ドル/bbl（+48.88%）。1978→79年に**世界供給量増と原油輸入費用高騰が同居した**という観察だけでは、供給・世界総需要・予備的需要の成分を識別できない。

## 識別に必要なもの

Kilian (2010), *Oil Price Volatility: Origins and Effects* （WTO公開）https://www-server1.wto.org/spanish/res_s/publications_s/wtr10_forum_s/wtr10_kilian_s.htm は、原油価格変動を**供給ショック・世界の実体経済活動に伴う需要ショック・将来の供給不安を反映する石油市場固有の需要ショック**に分けて考えることの重要性を指摘。石油生産量、世界実体活動、実質原油価格に関する時系列モデル等を用いても、ラグ、同時点制約、在庫、期待の扱いなど**追加の識別仮定**が要る。本データセットは油価・供給の記述統計なので、SVAR等の因果識別を実施していない。

関連する異なる実証設計として、日本銀行（2026年4月）『展望レポート』BOX2図表B2-8 https://www.boj.or.jp/mopo/outlook/gor2604b.pdf は、**同サイズの輸入物価上昇を設定したモデルシミュレーション**で、原油価格上昇ショックと円安ショックのGDPデフレーターの反応が逆向きになることを示す。ただしこれは実測値そのものではなく、モデルの仮定に依存する。
