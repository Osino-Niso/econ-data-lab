# econ-data-lab

Zenn上の名称: **経済データ実験室**

経済学部生が授業でつまずきやすい統計・計量経済学の論点を、数式・Python・R・実データの間をつなぎながら検証するためのリポジトリです。

## 方針

- 初学者が混同しやすい論点を明示し、順序立てて解消する
- 感情表現より、概念上の混乱点とその解消を優先する
- 可能な限り Python と R の両方で同じ概念を確認する
- 公開前に説明・コード・数式を検証する
- 記事はまず無料公開し、学習成果・執筆力・再現可能な成果物を蓄積する

## 構成

- `articles/`: Zenn掲載を想定したMarkdown原稿
- `code/`: 記事中のPython / Rコードの再現用ファイル

## 現在の原稿

- `articles/bernoulli-one-trial.md`
  - 「ベルヌーイ分布は『1回』なのに、なぜ確率分布なのか？」

## Zenn

記事原稿はZennのGitHub連携を想定したFront Matter形式で管理します。
公開前は必ず `published: false` とし、内容確認後に明示的に公開へ切り替えます。
