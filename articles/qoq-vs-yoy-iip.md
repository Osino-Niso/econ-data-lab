経済統計の授業で、前期比と前年同期比を扱いました。

どちらも「どれくらい増えたか、減ったか」を表す数字です。

そのため最初は、

**同じデータを見ているなら、だいたい同じような動きをするのではないか**

と思っていました。

ところが、実際の経済統計を見るとそうとは限りません。

ある時期には、

- 前期比ではプラス
- 前年同期比ではマイナス

となり、別の時期には逆の組み合わせになることもあります。

では、

**同じ経済データを見ているのに、前年比と前期比で印象が違って見えるのはなぜでしょうか。**

この記事では、小さな架空データで比較対象の違いを確認したあと、経済産業省の鉱工業生産指数を使って、PythonとRでも実際に確かめます。

なお、この記事では四半期データを扱うため、本文では厳密に **前年同期比** と呼びます。タイトルでは、より一般的な言い方として「前年比」を使っています。

## 先に結論

前期比と前年同期比では、そもそも **比較している相手が違います。**

前期比は、

> 今は、直前の四半期より上向いているのか

を見るのに向いています。

一方、前年同期比は、

> 今の水準は、1年前の同じ時期より高いのか

を見るのに向いています。

そのため、

**最近は回復しているが、まだ1年前の水準には戻っていない**

なら、

- 前期比：プラス
- 前年同期比：マイナス

となりえます。

逆に、

**1年前よりは高い水準にいるが、直近では減速している**

なら、

- 前期比：マイナス
- 前年同期比：プラス

となりえます。

どちらか片方が間違っているわけではありません。

見ている時間軸が違います。

さらに実際の経済統計では季節変動があるため、前期比では季節調整済系列、前年同期比では原系列を使う、といった違いもあります。

したがって、数字を見るときには、

**何％増減したかだけでなく、「何と比べた数字なのか」まで確認する必要があります。**

## 1. 前期比と前年同期比は何を比べているのか

四半期の値を $X_t$ とします。

前期比は、現在の値と1つ前の四半期を比較します。

$$
\text{前期比}
=
\frac{X_t-X_{t-1}}{X_{t-1}}
\times100
$$

一方、前年同期比は、現在の値と4四半期前を比較します。

$$
\text{前年同期比}
=
\frac{X_t-X_{t-4}}{X_{t-4}}
\times100
$$

並べると違いは単純です。

| 指標 | 比較する相手 |
| --- | --- |
| 前期比 | 1四半期前 |
| 前年同期比 | 4四半期前 |

たとえば2025年1–3月期なら、

- 前期比：2024年10–12月期との比較
- 前年同期比：2024年1–3月期との比較

です。

同じ2025年1–3月期の数字を見ていても、比較する相手が違います。

ここが、2つの数字が違った動きをする出発点です。

## 2. 小さな架空データで考える

まず、季節性などは無視して、次のような架空の指数を考えます。

| 四半期 | 指数 |
| --- | ---: |
| 2024Q1 | 100 |
| 2024Q2 | 105 |
| 2024Q3 | 98 |
| 2024Q4 | 90 |
| 2025Q1 | 95 |

2025Q1だけを見ると、指数は95です。

前期比では、2024Q4の90と比較するので、

$$
\frac{95-90}{90}\times100
\approx5.6\%
$$

です。

つまり、**前期比では5.6%増** となります。

一方、前年同期比では2024Q1の100と比較します。

$$
\frac{95-100}{100}\times100
=-5.0\%
$$

したがって、**前年同期比では5.0%減** です。

同じ95という値を見ているのに、

```text
前期比       +5.6%
前年同期比   -5.0%
```

となりました。

これは矛盾ではありません。

このデータでは、

> 直前の90からは回復したが、1年前の100にはまだ戻っていない

からです。

前期比は直近の **方向** を、前年同期比は1年前と比べた **水準の変化** を捉えやすい、と考えると分かりやすくなります。

## 3. なぜ前期比では季節調整が必要なのか

実際の経済データでは、もう一つ問題があります。

**季節変動** です。

たとえば、生産、消費、雇用などには、年末年始、長期休暇、天候、営業日数などによって、毎年ある程度繰り返される動きがあります。

原データのまま2025Q1と2024Q4を比較すると、

「経済活動そのものが変化したから数字が動いた」のか、

「毎年Q1とQ4ではそもそも数字が違いやすい」のか、

区別しにくくなります。

そこで、前期比を見るときには、季節的に繰り返される動きを取り除いた **季節調整済指数** を使うことがあります。

経済産業省の鉱工業指数でも、前月比・前期比には季節調整済指数が使われています。

一方、前年同期比は、

```text
2025Q1 と 2024Q1
```

のように同じ季節どうしを比較します。

そのため季節変動の影響を受けにくく、原指数を使った比較ができます。

ここで重要なのは、

**前期比と前年同期比では、比較する時点だけでなく、実務上使う系列も異なることがある**

という点です。

この記事で「同じデータ」と呼んでいるのは、厳密には、

> 同じ経済現象を表す同じ統計を、異なる比較方法・系列から見る

という意味です。

## 4. 実際の鉱工業生産指数を見てみる

ここからは、経済産業省の **鉱工業生産指数** を使います。

今回は「生産」を見ます。

2025年3月分の確報で公表されている四半期の変化率は、次のようになっています。

| 四半期 | 前期比 | 前年同期比 |
| --- | ---: | ---: |
| 2024Q1 | -5.2% | -3.9% |
| 2024Q2 | +2.1% | -3.3% |
| 2024Q3 | +0.3% | -1.8% |
| 2024Q4 | +0.4% | -1.5% |
| 2025Q1 | -0.3% | +1.0% |

かなり面白い動きになっています。

2024Q2を見ると、

```text
前期比       +2.1%
前年同期比   -3.3%
```

です。

前期比だけを見ると、生産は増えています。

しかし前年同期比では、まだ前年を下回っています。

つまり、

> 直前の落ち込みからは回復しているが、前年同期と比べると低い水準にいる

という2つの情報が同時に存在しています。

2024Q3、2024Q4も同じで、前期比はプラスですが前年同期比はマイナスです。

そして2025Q1になると、符号が逆転します。

```text
前期比       -0.3%
前年同期比   +1.0%
```

今度は、

> 1年前よりは高いが、直前の四半期からは少し下がった

と読めます。

「良くなった」「悪くなった」の一言だけでは、こうした違いを表しきれません。

## 5. Pythonで前期比と前年同期比を計算する

ここからは、指数そのものから変化率を計算します。

使用するのは、

- 季節調整済指数
- 原指数

です。

```python
import numpy as np

quarters = np.array([
    "2023Q1", "2023Q2", "2023Q3", "2023Q4",
    "2024Q1", "2024Q2", "2024Q3", "2024Q4", "2025Q1",
])

sa_index = np.array([
    103.5, 104.8, 103.3, 104.4,
    99.0, 101.1, 101.4, 101.8, 101.5,
])

original_index = np.array([
    104.0, 102.4, 102.7, 106.5,
    99.9, 99.0, 100.9, 104.9, 100.9,
])

qoq = np.full(sa_index.shape, np.nan)
qoq[1:] = (sa_index[1:] / sa_index[:-1] - 1) * 100

yoy = np.full(original_index.shape, np.nan)
yoy[4:] = (original_index[4:] / original_index[:-4] - 1) * 100
```

2024Q1以降を表示すると、

```text
quarter  qoq  yoy
 2024Q1  -5.2  -3.9
 2024Q2   2.1  -3.3
 2024Q3   0.3  -1.8
 2024Q4   0.4  -1.5
 2025Q1  -0.3   1.0
```

となります。

1つ前との比較と4四半期前との比較を変えただけで、符号まで違う時期があります。

数字の表だけでも確認できますが、図にすると「2つの指標が別の方向を向く時期」がかなり見えやすくなります。

## 7. Rでも同じ計算をする

Rでも同じ指数を使います。

```r
quarters <- c(
  "2023Q1", "2023Q2", "2023Q3", "2023Q4",
  "2024Q1", "2024Q2", "2024Q3", "2024Q4", "2025Q1"
)

sa_index <- c(
  103.5, 104.8, 103.3, 104.4,
  99.0, 101.1, 101.4, 101.8, 101.5
)

original_index <- c(
  104.0, 102.4, 102.7, 106.5,
  99.9, 99.0, 100.9, 104.9, 100.9
)

qoq <- c(
  NA,
  (sa_index[-1] / sa_index[-length(sa_index)] - 1) * 100
)

yoy <- c(
  rep(NA, 4),
  (original_index[5:length(original_index)] /
    original_index[1:(length(original_index) - 4)] - 1) * 100
)
```

Pythonと同じ計算をしています。

ここでコードを載せる目的は、PythonやRそのものを学ぶことではありません。

**比較する基準を変えるだけで、同じ統計から違う動きが見えることを再現するため**です。

## 8. 「都合のいい数字だけ見せる」と何が起こるか

ここで、授業中に特に印象に残った話につながります。

前期比と前年同期比で違う見え方をするなら、片方だけを選べば、受け手に与える印象も変えられます。

たとえば2025Q1の鉱工業生産なら、

> 鉱工業生産は前期比0.3%低下

とも書けます。

一方で、

> 鉱工業生産は前年同期比1.0%上昇

とも書けます。

どちらも正しい数字です。

しかし、前者だけなら「生産が悪化した」という印象を受けやすく、後者だけなら「生産が改善した」という印象を受けるかもしれません。

2024Q2なら逆です。

```text
前期比       +2.1%
前年同期比   -3.3%
```

なので、

> 生産は前期比2.1%増加した

とだけ書けば回復感が強くなります。

一方、

> 生産は前年同期比3.3%減少した

とだけ書けば、かなり違った印象になります。

ただし、ここから

**「片方を使うこと自体がごまかしだ」**

と考えるのも違うと思います。

知りたいことによって適した比較方法が違うからです。

直近の方向転換を知りたいなら前期比を見る理由があります。

前年と比べた水準を知りたいなら前年同期比を見る理由があります。

問題になるのは、比較方法の違いを無視して、都合のよい数字だけで全体を説明しようとすることです。

統計を見る側としては、

> この数字は何と比べているのか？

を一度確認するだけでも、かなり見え方が変わります。

## 9. 前年同期比にも「1年前」の影響がある

前年同期比は季節性を避けやすい一方、別の注意点があります。

**1年前の数字が分母になること**です。

たとえば、前年に災害などで経済活動が大きく落ち込んでいたとします。

翌年にある程度普通の水準へ戻れば、前年同期比は大きなプラスになる可能性があります。

しかし、それだけを見て、

「直近で急激に経済活動が加速している」

とは限りません。

大きな前年比が出た理由の一部が、

**今年の値が特別高いからではなく、1年前の値が低かったから**

という場合があるからです。

総務省統計局も、消費者物価指数の説明の中で、前年同月比には足元の動きだけでなく **1年前の動きによるものも含まれるため注意が必要** と説明しています。

逆に前年が一時的に高ければ、現在の水準がそれほど悪くなくても前年同期比はマイナスになりえます。

前年比を見るときには、現在だけでなく、

**比較対象になっている1年前に何が起きていたか**

も確認する必要があります。

## 10. 前期比だけを見ればよいわけでもない

では、直近の変化が分かる前期比だけを見ればよいのでしょうか。

そうとも限りません。

たとえば、

```text
100 → 80 → 84
```

と動いた場合、最後の前期比は、

$$
\frac{84-80}{80}\times100
=5\%
$$

です。

前期比だけなら5%増です。

しかし最初の100と比べると、まだ84までしか戻っていません。

短期的な方向を見るには前期比が便利でも、それだけで水準まで判断すると見落としが生じます。

逆に前年同期比だけでは、直近で方向転換した瞬間を捉えるのが遅れることがあります。

結局、

**前期比と前年同期比は競合する指標ではなく、違う質問に答えている指標**

と考えるのが自然だと思います。

## 11. 経済統計を見るときに確認したいこと

今回の実験から、経済統計の増減率を見るときには少なくとも次を確認したいと思いました。

1. 何の統計か
2. 原指数か季節調整済指数か
3. 何と比較しているか
4. 比較対象の時期に特殊な出来事がなかったか
5. もう一方の比較方法ではどう見えるか

さらに、鉱工業生産指数は日本経済全体そのものではありません。

製造業などの生産活動を見る重要な指標ですが、鉱工業生産だけで日本経済全体の良し悪しを判断できるわけではありません。

今回の記事で確認したかったのは景気判断そのものというより、

**同じ統計でも、比較方法によって見えている側面が変わる**

という点です。

## まとめ

最初の疑問は、

> 同じ経済データを見ているのに、前年比と前期比で印象が違って見えるのはなぜか？

というものでした。

理由は、比較している相手が違うからです。

前期比は $X_t$ と $X_{t-1}$ を比較します。

前年同期比は $X_t$ と $X_{t-4}$ を比較します。

そのため、

> 最近は回復しているが、まだ1年前より低い

なら、

```text
前期比       プラス
前年同期比   マイナス
```

になりえます。

逆に、

> 1年前より高いが、直近では少し落ち込んだ

なら、

```text
前期比       マイナス
前年同期比   プラス
```

になりえます。

実際、鉱工業生産指数では2025Q1に、

```text
前期比       -0.3%
前年同期比   +1.0%
```

という組み合わせが確認できました。

どちらか一方が「本当の数字」で、もう一方が間違っているわけではありません。

それぞれ違う時間軸から同じ経済活動を見ています。

だから経済統計を見るときは、

> 何％増えたか

だけでなく、

> **何と比べて何％増えたのか**

まで確認する必要があります。

数字そのものだけでなく、**その数字を作った比較方法まで読む**。

これが今回の結論です。
