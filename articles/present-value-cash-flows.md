金融工学の授業でキャッシュフロー図を見たとき、私は最初、そこに並んでいる金額をそのまま足してしまいました。

たとえば、

```text
1年後   +40
2年後   +20
3年後   +30
```

と書いてあれば、

```text
40 + 20 + 30 = 90
```

だから「合計90」と考えればよいのではないか、という感覚です。

金額だけを見れば、この足し算自体はできます。

ただし、投資の価値を考えるときには、この90をそのまま使うことはできません。

なぜなら、**1年後の40と3年後の30は、受け取る時点が違うからです。**

では、時点が違うだけで、なぜ同じ「円」をそのまま足してはいけないのでしょうか。

この記事では、この疑問を現在価値の考え方から整理します。

## 先に結論

時点の違うキャッシュフローをそのまま足した数字は、**名目額の合計**としては意味があります。

しかし、その数字は「ある1つの時点で見た価値」にはなっていません。

投資判断では、

- 今日の100万円
- 1年後の100万円
- 3年後の100万円

を同じものとして扱わず、まず同じ時点にそろえて比較します。

現在時点にそろえるなら、将来のキャッシュフローを割引いて **現在価値（Present Value, PV）** へ変換します。

年利率を $r$、$t$ 年後のキャッシュフローを $CF_t$ とすると、現在価値は

$$
PV_t=\frac{CF_t}{(1+r)^t}
$$

です。

複数のキャッシュフローがあるなら、各時点のキャッシュフローをそれぞれ現在価値に直してから足します。

$$
PV=\sum_{t=1}^{T}\frac{CF_t}{(1+r)^t}
$$

重要なのは、**足し算をしてはいけないのではなく、足す前に「価値を測る時点」をそろえる必要がある**ということです。

## 1. 今日の100万円と1年後の100万円は同じか

まず、いちばん単純な例を考えます。

今100万円を持っていて、年利5%で1年間運用できるとします。

1年後には、

$$
100\times1.05=105
$$

万円になります。

逆に考えると、1年後の100万円と同じ価値を今日用意するには、

$$
\frac{100}{1.05}\approx95.24
$$

万円あれば足ります。

つまり、年利5%という前提では、

```text
今日の約95.24万円  ↔  1年後の100万円
```

が対応します。

この関係が現在価値の基本です。

将来価値を求める式

$$
FV=PV(1+r)^t
$$

を $PV$ について解けば、

$$
PV=\frac{FV}{(1+r)^t}
$$

になります。

現在価値は、将来の金額を「今日の価値」に読み替えたものだと考えられます。

## 2. なぜ時点が違うと、そのまま足せないのか

ここで、1年後、2年後、3年後にそれぞれ100万円を受け取るとします。

名目額だけを合計すると、

$$
100+100+100=300
$$

万円です。

この300万円は、将来受け取る金額の単純な合計としては間違っていません。

しかし、年利5%で現在価値を計算すると、

| 受取時点 | キャッシュフロー | 現在価値 |
| --- | ---: | ---: |
| 1年後 | 100万円 | 約95.24万円 |
| 2年後 | 100万円 | 約90.70万円 |
| 3年後 | 100万円 | 約86.38万円 |

となります。

![](/images/present-value-cash-flows/timeline.png)

合計すると、

$$
95.24+90.70+86.38\approx272.32
$$

万円です。

名目額では300万円ですが、現在価値では約272.32万円です。

これは「将来の300万円が実際には272.32万円しかもらえない」という意味ではありません。

将来には合計300万円を受け取ります。

ただし、**その300万円を今日という同じ時点の価値に換算すると約272.32万円になる**という意味です。

この区別が重要です。

## 3. 「円」だけでなく「いつの円か」をそろえる

私が最初につまずいたのは、キャッシュフローを

```text
40億円
20億円
30億円
```

のように、単なる金額の列として見ていたからだと思います。

しかし、実際には

```text
1年後の40億円
2年後の20億円
3年後の30億円
```

です。

同じ円建てでも、受け取る時点が違います。

そこで、投資評価では

```text
1年後の40億円 → 今日の価値へ変換
2年後の20億円 → 今日の価値へ変換
3年後の30億円 → 今日の価値へ変換
```

としてから合計します。

感覚的には、長さを足すときに

```text
1 m + 50 cm
```

をそのまま「51」としないのと少し似ています。

単位そのものはどちらも長さですが、共通の基準に直してから足します。

キャッシュフローの場合は、物理的な単位換算とは違いますが、**価値を測る時点をそろえる**という操作を行います。

## 4. 同じ合計額でも、早く受け取る方が価値は高くなる

時点をそろえる必要性は、同じ名目合計の2つの案件を比べると分かりやすくなります。

割引率を10%として、次の2つを考えます。

### 案件A

```text
1年後  70万円
2年後  50万円
```

### 案件B

```text
1年後  50万円
2年後  70万円
```

どちらも名目額の合計は120万円です。

![](/images/present-value-cash-flows/projects.png)

しかし現在価値は、案件Aが

$$
\frac{70}{1.1}+\frac{50}{1.1^2}
\approx104.96
$$

万円、案件Bが

$$
\frac{50}{1.1}+\frac{70}{1.1^2}
\approx103.31
$$

万円です。

合計額は同じなのに、案件Aの現在価値の方が約1.65万円高くなりました。

違いは、案件Aの方が多くのお金を早く受け取れることです。

早く受け取った資金は、その後運用することができます。

そのため、正の金利・割引率を前提にすると、同じ金額なら早く受け取る方が現在価値は高くなります。

## 5. 現在価値とNPVは同じではない

現在価値を理解すると、次に出てくるのが **正味現在価値（Net Present Value, NPV）** です。

たとえば、今日100万円を投資すると、1年後と2年後に60万円ずつ受け取れる案件を考えます。

割引率が10%なら、将来キャッシュフローの現在価値は

$$
\frac{60}{1.1}+\frac{60}{1.1^2}
\approx104.13
$$

万円です。

ここから今日支払う100万円を引くと、

$$
NPV
=-100
+\frac{60}{1.1}
+\frac{60}{1.1^2}
\approx4.13
$$

万円です。

つまり、

- PV：将来キャッシュフローを現在時点の価値へ直したもの
- NPV：初期投資も含め、現在時点で見た正味の価値

と区別できます。

私自身、この2つを一度混同しました。

「割り引いて足した値」なら何でもNPVなのではなく、**何を含めた値なのか**を確認する必要があります。

## 6. Pythonで確認する

同じ計算をPythonで確認します。

```python
def present_value(cash_flow, t, rate):
    return cash_flow / (1 + rate) ** t

rate = 0.05
cash_flows = [100, 100, 100]

pv_values = [
    present_value(cf, t, rate)
    for t, cf in enumerate(cash_flows, start=1)
]

for t, (cf, pv) in enumerate(zip(cash_flows, pv_values), start=1):
    print(f"{t}年後: CF={cf:.2f}, PV={pv:.2f}")

print(f"名目合計: {sum(cash_flows):.2f}")
print(f"現在価値合計: {sum(pv_values):.2f}")
```

出力はおおよそ、

```text
1年後: CF=100.00, PV=95.24
2年後: CF=100.00, PV=90.70
3年後: CF=100.00, PV=86.38
名目合計: 300.00
現在価値合計: 272.32
```

となります。

さらに、先ほどの案件A・Bも比較できます。

```python
rate = 0.10

project_a = 70 / (1 + rate) + 50 / (1 + rate) ** 2
project_b = 50 / (1 + rate) + 70 / (1 + rate) ** 2

print(f"案件AのPV: {project_a:.2f}")
print(f"案件BのPV: {project_b:.2f}")
```

名目合計はどちらも120万円ですが、現在価値は一致しません。

## 7. Rで確認する

Rでも同じ計算をします。

```r
present_value <- function(cash_flow, t, rate) {
  cash_flow / (1 + rate)^t
}

rate <- 0.05
cash_flows <- c(100, 100, 100)
times <- 1:3

pv_values <- mapply(present_value, cash_flows, times,
                    MoreArgs = list(rate = rate))

result <- data.frame(
  year = times,
  cash_flow = cash_flows,
  present_value = pv_values
)

print(result)
cat(sprintf("名目合計: %.2f\n", sum(cash_flows)))
cat(sprintf("現在価値合計: %.2f\n", sum(pv_values)))
```

Pythonと同じく、現在価値の合計は約272.32万円になります。

## 8. 割引率は何でもよいわけではない

ここまでの例では、5%や10%という割引率をあらかじめ与えました。

しかし、実際の投資評価では、**どの割引率を使うか自体が重要な問題**です。

割引率は単に「インフレ率だから引く」というものではありません。

評価する対象や前提によって、金利、機会費用、リスク、資本コストなどとの関係を考える必要があります。

この記事では、

> 時点の違うキャッシュフローを比較するには、同じ時点の価値へ変換する

という点に絞りました。

「そのとき何%で割り引くべきか」は、次の段階の問題です。

## 9. よくある混同を整理する

最後に、今回自分がつまずいた点を整理します。

### 「時点の違う金額は足してはいけない」？

名目額の総額を知りたいだけなら足せます。

ただし、**投資価値として比較するなら、その単純合計だけでは不十分**です。

### 「割り引いた値」なら全部NPV？

違います。

将来キャッシュフローの現在価値がPVで、初期投資まで含めた正味の価値がNPVです。

### 「現在価値が低い」というのは損をしているということ？

そうではありません。

現在価値は、将来の金額を今日時点の価値で表し直したものです。

金利が正なら、同じ100万円でも受け取りが先になるほど現在価値は小さくなります。

## 10. まとめ

この記事で整理したかったことは、次の3点です。

1. 時点の違うキャッシュフローは、名目額としては足せる。
2. ただし、投資判断に使うには、まず同じ時点の価値へそろえる必要がある。
3. そのために将来のキャッシュフローを現在価値へ割り引く。

私自身、最初は「同じ円なのだから、そのまま足してよいのでは」と思っていました。

しかし、キャッシュフロー図は単なる金額の一覧ではなく、**いつ発生するかまで含めて読むもの**だと分かると、現在価値を使う理由がかなりはっきりしました。

今後は、ここからさらに

- 割引率をどう決めるか
- NPVでどう投資判断するか
- 資本コストやWACCとどうつながるか

という論点へ進めます。
