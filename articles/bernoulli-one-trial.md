ベルヌーイ分布は、一般に「1回の試行を表す確率分布」と説明されます。

ここで疑問が生じます。

1回しか試行しないのであれば、実際に得られる結果は0か1のどちらか一つです。それにもかかわらず、なぜ「分布」を考えるのでしょうか。

この疑問を整理するには、

- 1回の試行
- 確率変数
- 実際に観測された値

を区別する必要があります。

## 先に結論

ベルヌーイ分布の「1回」とは、

**1つの確率変数が、1回の試行の結果を表している**

という意味です。

たとえば、成功確率が (p) の試行について、

[
X =
\begin{cases}
1 & \text{成功} \\
0 & \text{失敗}
\end{cases}
]

とします。

このとき、

[
P(X=1)=p, \qquad P(X=0)=1-p
]

です。

実際に試行すれば、観測される値は0か1のどちらか一つに決まります。しかし、確率変数 (X) には、0を取る確率と1を取る確率の両方が定められています。

この確率の割り当てがベルヌーイ分布です。

## 1. 「1回の試行」と「1つの観測値」は同じではない

成功確率30%の試行を1回行うとします。

成功なら1、失敗なら0として、

[
X =
\begin{cases}
1 & \text{成功} \\
0 & \text{失敗}
\end{cases}
]

と定義すると、

[
P(X=1)=0.3, \qquad P(X=0)=0.7
]

です。

ここで実際に試行して成功したなら、観測された値は (X=1) です。

一方、

[
P(X=0)=0.7, \qquad P(X=1)=0.3
]

という記述は、確率変数 (X) がどの値をどの確率で取るかを表しています。

実際に得られた値と、その値を生み出す確率分布は区別する必要があります。

## 2. 確率変数と実現値

ベルヌーイ分布の場合、確率変数 (X) が取り得る値は0と1です。

(p=0.3) なら、

| (x) | (P(X=x)) |
| --- | ---: |
| 0 | 0.7 |
| 1 | 0.3 |

となります。

実際に1回観測して1が得られたとしても、1はベルヌーイ分布そのものではありません。確率変数 (X) から得られた一つの実現値です。

## 3. ベルヌーイ分布の定義

一般に、

[
P(X=1)=p, \qquad P(X=0)=1-p
]

を満たす確率変数 (X) について、

[
X \sim \mathrm{Bernoulli}(p)
]

と書きます。

確率質量関数としてまとめると、

[
P(X=x)=p^x(1-p)^{1-x},
\qquad x\in\{0,1\}
]

です。

(x=1) を代入すると (P(X=1)=p)、(x=0) を代入すると (P(X=0)=1-p) になります。

取り得る値が二つしかなくても、それぞれに確率が割り当てられているため、確率分布として扱えます。

## 4. Pythonで確認する

まず、何度も試行する前に (p=0.3) の確率そのものを確認します。

```python
import numpy as np

p = 0.3

values = np.array([0, 1])
probabilities = np.array([1 - p, p])

for value, probability in zip(values, probabilities):
    print(f"P(X={value}) = {probability}")
```

出力は次のようになります。

```text
P(X=0) = 0.7
P(X=1) = 0.3
```

この時点では大量の試行は必要ありません。0と1にどの確率が割り当てられているかが定まれば、ベルヌーイ分布は定義できます。

次に、同じベルヌーイ試行を多数回生成します。

```python
rng = np.random.default_rng(0)

x = rng.binomial(n=1, p=0.3, size=10000)

print(x.mean())
```

ベルヌーイ確率変数は0か1しか取らないため、平均はそのまま「1が出た割合」です。試行回数を増やすと、この値は (p=0.3) の近くに現れます。

## 5. Rで確認する

Rでは `dbinom()` を使って、試行回数1回の二項分布として確率を計算できます。

```r
p <- 0.3
x <- 0:1

dbinom(x, size = 1, prob = p)
```

出力は、

```text
[1] 0.7 0.3
```

となり、

[
P(X=0)=0.7, \qquad P(X=1)=0.3
]

を表します。

多数回の試行は `rbinom()` で生成できます。

```r
set.seed(0)

x <- rbinom(
  n = 10000,
  size = 1,
  prob = 0.3
)

mean(x)
```

こちらも0.3に近い値になります。

## 6. 何度も試行するのは何のためか

ここで重要なのは、

**10000回試行したからベルヌーイ分布が生まれたわけではない**

という点です。

10000回の試行を

[
X_1, X_2, \ldots, X_{10000}
]

と表すなら、それぞれの (X_i) がベルヌーイ分布に従っています。

[
X_i \sim \mathrm{Bernoulli}(0.3)
]

多数回観測することで、(P(X=1)=0.3) という確率構造が、実際のデータの割合として確認しやすくなっているだけです。

## 7. ベルヌーイ分布と二項分布

独立なベルヌーイ試行を (n) 回行い、

[
Y=X_1+X_2+\cdots+X_n
]

とします。

各 (X_i) は成功なら1、失敗なら0なので、(Y) は「(n) 回中何回成功したか」を表します。

このとき、

[
Y \sim \mathrm{Binomial}(n,p)
]

となります。

したがって、

- ベルヌーイ分布：1回の試行結果
- 二項分布：複数回の独立なベルヌーイ試行における成功回数

と整理できます。

## 8. よくある混同

### 「1回しか試行しないなら、分布は存在しない」

確率分布は、確率変数が取り得る値と、それぞれの値を取る確率を表します。実際に何回観測したかとは別の問題です。

### 「何度も試行して初めてベルヌーイ分布になる」

各1回の試行を表す確率変数が、それぞれベルヌーイ分布に従います。多数回のシミュレーションは、その確率構造を観察する手段です。

### 「(p=0.3) なら1回の試行で0.3だけ成功する」

1回の実現値は0または1です。0.3は、1という結果に割り当てられた確率です。

## まとめ

ベルヌーイ分布の「1回」とは、1回の試行を1つの確率変数で表しているという意味です。

[
X \sim \mathrm{Bernoulli}(p)
]

なら、

[
P(X=0)=1-p, \qquad P(X=1)=p
]

です。

実際に1回試行すれば、観測値は0か1のどちらか一つになります。しかし、その観測値と、「確率変数 (X) が0と1をどの確率で取るのか」という確率分布は別のものです。

したがって、

> 1回しか試行しないのに、なぜ分布を考えられるのか？

という疑問に対する答えは、

**確率分布は「何回観測したか」を表すものではなく、確率変数が取り得る値と、その値を取る確率を表すものだから**

となります。
