ベルヌーイ分布は、よく「1回の試行を表す確率分布」と説明されます。

ここで、私は最初に少し引っかかりました。

**1回しか試行しないなら、実際に得られる結果は0か1のどちらか一つだけです。それなのに、なぜ「分布」を考えるのでしょうか。**

この疑問を解く鍵は、

- 1回の試行
- 確率変数
- 確率分布
- 実際に観測された値

を区別することです。

この記事では、成功確率30%の簡単な例を使いながら、PythonとRでも確認してみます。

## 先に結論

ベルヌーイ分布の「1回」とは、

**1回の試行結果を、1つの確率変数 $X$ で表している**

という意味です。

言い換えると、**ベルヌーイ分布では「1個の $X$ が1回分」**です。

その1回の試行で起こりうる結果を、

- $X=1$：成功
- $X=0$：失敗

のように表します。

成功確率を $p$ として、

$$
X =
\begin{cases}
1 & \text{成功} \\
0 & \text{失敗}
\end{cases}
$$

と定義すると、

$$
P(X=1)=p,\qquad P(X=0)=1-p
$$

です。

実際に1回試行すれば、この「1回分の $X$」は0か1のどちらか一つとして観測されます。

ただし、$X=0$ や $X=1$ という表記は、**1回の試行で起こりうる結果**を表しています。これらの結果にどの確率を割り当てるかを示したものが確率分布です。

一方、確率分布が表しているのは、**観測前の確率変数 $X$ が、どの値をどの確率で取りうるかというルール**です。

つまり、

> 「1回」は試行回数の話であり、「分布」は確率変数に対する確率の割り当ての話

です。

## 1. 「確率変数」と「実際に出た値」を分ける

成功確率30%の試行を考えます。

成功なら1、失敗なら0として、

$$
X =
\begin{cases}
1 & \text{成功} \\
0 & \text{失敗}
\end{cases}
$$

と定義します。

ここで大事なのは、$X=0$ と $X=1$ が「別々の試行」を表しているわけではないことです。

**1回の試行を表す1つの確率変数 $X$ があり、その1回の結果として0か1のどちらかを取る**、という関係です。

このとき、

$$
P(X=1)=0.3,\qquad P(X=0)=0.7
$$

です。

ここで、実際に1回試行して成功したとします。

そのとき観測された値は、

$$
x=1
$$

です。

しかし、

$$
P(X=0)=0.7,\qquad P(X=1)=0.3
$$

という確率の割り当てと、今回たまたま得られた $x=1$ は別のものです。

整理すると、次のようになります。

| 対象 | この例での意味 |
| --- | --- |
| 確率変数 $X$ | これから0または1を取る変数 |
| ベルヌーイ分布 | 0と1をどの確率で取るかというルール |
| 実現値 $x$ | 実際に観測された0または1 |

厳密には、確率変数は「確率的な試行の結果に数値を対応させる関数」です。

ただ、最初の段階では、

**「観測するたび値は変わりうるが、どんな値をどんな確率で取るかという法則を持つもの」**

と考えると理解しやすいと思います。

## 2. 取りうる値が2つだけでも「分布」である

$p=0.3$ のとき、ベルヌーイ確率変数の取りうる値と確率は次の2つだけです。

| $x$ | $P(X=x)$ |
| --- | ---: |
| 0 | 0.7 |
| 1 | 0.3 |

値が2つしかありませんが、

**「どの値を、どの確率で取るか」**

が完全に指定されています。

これが確率分布です。

一般に、

$$
P(X=1)=p,\qquad P(X=0)=1-p
$$

を満たすとき、

$$
X\sim\mathrm{Bernoulli}(p)
$$

と書きます。

確率質量関数を1本の式で書けば、

$$
P(X=x)=p^x(1-p)^{1-x},
\qquad x\in\{0,1\}
$$

です。

$x=1$ を代入すると $p$、$x=0$ を代入すると $1-p$ になります。

ここで重要なのは式を暗記することより、

**確率分布は「大量の観測値が並んだもの」ではない**

ということです。

大量のデータを集める前から、モデルとしてのベルヌーイ分布は定義できます。

## 3. 実際に1回だけ観測してみる

まずPythonで、$p=0.3$ のベルヌーイ分布そのものを数値で表してみます。

```python
import numpy as np

p = 0.3

values = np.array([0, 1])
probabilities = np.array([1 - p, p])

for value, probability in zip(values, probabilities):
    print(f"P(X={value}) = {probability}")
```

出力は、

```text
P(X=0) = 0.7
P(X=1) = 0.3
```

です。

次に、この分布に従う試行を**1回だけ**行ってみます。

```python
rng = np.random.default_rng(0)

single = rng.binomial(n=1, p=0.3)

print("single draw =", single)
```

GitHub Actions上で実際に実行した結果は、

```text
single draw = 0
```

でした。

ここで、

- $P(X=0)=0.7$, $P(X=1)=0.3$ は**分布**
- 今回実際に出力された $0$ は**実現値**

です。

今回の1回では0が出ましたが、別の1回では1が出ることもあります。1回の実現値が0だったからといって、ベルヌーイ分布そのものが「0だけを取る分布」になったわけではありません。

ここでは $p$ が既知で固定されたモデルとして考えているので、1回観測した後も、もとの確率モデルは

$$
X\sim\mathrm{Bernoulli}(0.3)
$$

のままです。

## 4. Rでも1回だけ観測してみる

Rでは、`dbinom()` を使って確率を確認できます。

ベルヌーイ分布は「試行回数1回の二項分布」として扱えるため、

```r
p <- 0.3
x <- 0:1

dbinom(x, size = 1, prob = p)
```

とすると、

```text
[1] 0.7 0.3
```

となります。

これは順に、

$$
P(X=0)=0.7,\qquad P(X=1)=0.3
$$

を表しています。

次に1回だけ乱数を生成します。

```r
set.seed(0)

single <- rbinom(
  n = 1,
  size = 1,
  prob = 0.3
)

print(single)
```

GitHub Actions上で実際に実行した結果は、

```text
[1] 1
```

でした。

Pythonでは同じ $p=0.3$ のベルヌーイ分布から1回生成して0が出ましたが、Rでは1が出ました。

これは矛盾ではありません。どちらも

$
P(X=0)=0.7,\qquad P(X=1)=0.3
$

という**同じ確率分布**に従う1回の試行ですが、実現値は試行ごとに異なりえます。

また、PythonとRでは乱数生成の仕組みが同一ではないため、どちらも乱数シードを0に設定していても同じ実現値になる必要はありません。

この違いはむしろ、

**確率分布と、そこから実際に得られた1つの値は別のもの**

だと確認するよい例になっています。

## 5. では、なぜ何度も試行するのか

ここまでなら、ベルヌーイ分布を考えるだけなら1回の試行で十分です。

それでは、教科書やプログラムで何千回も試行するのはなぜでしょうか。

理由の一つは、**理論上の確率構造を、観測データの中で確かめやすくするため**です。

$p=0.3$ のベルヌーイ確率変数では、

$$
E[X]
=0\times0.7+1\times0.3
=0.3
$$

なので、

$$
E[X]=p
$$

です。

ベルヌーイ確率変数は0か1しか取らないため、複数の観測値の平均は、そのまま「1が出た割合」になります。

Pythonで10,000回観測してみます。

```python
rng = np.random.default_rng(0)

sample = rng.binomial(n=1, p=0.3, size=10000)
sample_mean = sample.mean()

print("sample mean =", sample_mean)
```

GitHub Actions上での実行結果は、

```text
sample mean = 0.3001
```

でした。

Rでも同じことを確認します。

```r
set.seed(0)

sample <- rbinom(
  n = 10000,
  size = 1,
  prob = 0.3
)
sample_mean <- mean(sample)

print(sample_mean)
```

GitHub Actions上での実行結果は、

```text
[1] 0.3035
```

でした。

1回だけの実現値はPythonで0、Rで1と異なりましたが、10,000回観測した平均はどちらも0.3にかなり近くなっています。

この対比を見ると、

- **1回の実現値**は0か1のどちらか
- **分布のパラメータ**は $p=0.3$
- **多数回の平均**は $p$ に近づいていく

という違いが見えやすくなります。

ここで大事なのは、

**10,000回試行したからベルヌーイ分布が生まれたわけではない**

ということです。

10,000回の試行を

$$
X_1,X_2,\ldots,X_{10000}
$$

と書くなら、**$X_1$ が1回目、$X_2$ が2回目……というように、1つの確率変数 $X_i$ が1回分の試行結果を表します**を表しています。

それぞれの $X_i$ がベルヌーイ分布に従っています。

$$
X_i\sim\mathrm{Bernoulli}(0.3)
$$

多数回観測することで、もともと設定されていた $p=0.3$ という確率構造が、今回の0.3001や0.3035のように、観測された成功割合にも現れやすくなります。

これは大数の法則につながる話ですが、ここでは

**「分布を定義すること」と「多数回観測して分布の特徴を確認すること」は別**

と分かれば十分です。

## 6. ベルヌーイ分布と二項分布は何が違うのか

ベルヌーイ分布を学ぶと、二項分布との違いでも混乱しやすくなります。

同じ成功確率 $p$ をもつ独立なベルヌーイ試行を $n$ 回行い、

$$
Y=X_1+X_2+\cdots+X_n
$$

とします。

各 $X_i$ は0か1なので、$Y$ は「$n$ 回中、何回成功したか」を表します。

このとき、

$$
Y\sim\mathrm{Binomial}(n,p)
$$

です。

つまり、

- **ベルヌーイ分布**：1回の試行結果そのものを0か1で表す
- **二項分布**：複数回の独立なベルヌーイ試行の成功回数を表す

と整理できます。

ベルヌーイ分布の「1回」という言葉は、ここで二項分布の「$n$ 回」と対比されているわけです。

## 7. よくある混同

### 「1回しか試行しないなら、分布は存在しない」

存在します。

確率分布は、実際に何回観測したかではなく、確率変数がどんな値をどんな確率で取るかを表すものです。

### 「何度も試行して初めてベルヌーイ分布になる」

そうではありません。

各1回の試行を表す確率変数が、それぞれベルヌーイ分布に従います。

多数回のシミュレーションは、その確率構造を観察しやすくするためのものです。

### 「$p=0.3$ なら、1回の結果が0.3になる」

1回の実現値は0または1です。

0.3は、1という結果に割り当てられた確率です。

### 「ベルヌーイ分布は、0と1を大量に並べたヒストグラムのこと」

ヒストグラムは、実際に観測したデータの度数や割合を可視化したものです。

一方、ベルヌーイ分布は、

$$
P(X=0)=1-p,\qquad P(X=1)=p
$$

という理論上の確率の割り当てです。

観測回数を増やせばヒストグラムの割合はこの確率に近づいていきますが、両者は同じものではありません。

## まとめ

最初の疑問に戻ります。

> ベルヌーイ分布は「1回の試行」を表すのに、なぜ確率分布を考えられるのか？

答えは、

**ベルヌーイ分布では、1つの確率変数 $X$ が1回の試行を表し、その $X$ が0と1のどちらをどの確率で取るかを表したものが確率分布だから**

です。

つまり、ベルヌーイ分布では、**1つの確率変数 $X$ が1回分の試行結果を表します**であり、$X=0$ と $X=1$ はその1回で起こりうる2つの結果です。

$$
X\sim\mathrm{Bernoulli}(p)
$$

なら、

$$
P(X=0)=1-p,\qquad P(X=1)=p
$$

です。

実際に1回観測すれば、得られる値は0か1のどちらか一つだけです。

しかし、その一つの観測値と、0・1にどのような確率が割り当てられているかという確率分布は別のものです。

この区別ができると、ベルヌーイ分布だけでなく、その先の二項分布、標本平均、大数の法則なども整理しやすくなります。
