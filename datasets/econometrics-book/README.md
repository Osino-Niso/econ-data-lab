# 『例題で身につく計量経済学 I』最終課題データ

`final_project_2025.csv` は、Zenn Book『例題で身につく計量経済学 I』の最終課題で使用する固定スナップショットです。

## 出典

総務省統計局「家計調査」2025年（e-Stat）をもとに、都道府県庁所在市等47地域について、二人以上の世帯のうち勤労者世帯の `実収入` と `消費支出` を抽出・整形して作成しています。

- e-Stat データベース: https://www.e-stat.go.jp/dbview?sid=0002070003
- 2025年 詳細結果表: https://www.e-stat.go.jp/stat-search/files?cycle=7&tclass=000000330002&year=20250

## 列

- `city`: 都道府県庁所在市等。東京都は東京都区部。
- `income`: 1世帯当たり1か月間の平均実収入（円）。
- `consumption`: 1世帯当たり1か月間の平均消費支出（円）。

追加掲載される川崎市・相模原市・浜松市・堺市・北九州市、全国・地方・都市階級などの集計行は含めていません。

このCSVは、教材の分析手順を同じ数値で再現できるようにするための固定版です。最新値の確認やデータ定義の確認には、上記の公式統計を参照してください。
